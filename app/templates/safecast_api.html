The Safecast API

Query and add to the Safecast dataset with your own application.

API Endpoint

The Safecast API is available at:

https://api.safecast.org/

All API requests should be made to this base URL with the appropriate endpoint path.

Available Resources
Users
  • GET /api/v1/users - List users
  • GET /api/v1/users/{id} - Get user details
  • POST /api/v1/users - Create user
Measurements
  • GET /api/v1/measurements - List measurements
  • GET /api/v1/measurements/{id} - Get measurement
  • POST /api/v1/measurements - Submit measurement
bGeigie Imports
  • GET /api/v1/bgeigie_imports - List imports
  • GET /api/v1/bgeigie_imports/{id} - Get import
  • POST /api/v1/bgeigie_imports - Upload log
Devices
  • GET /api/v1/devices - List devices
  • GET /api/v1/devices/{id} - Get device
  • POST /api/v1/devices - Register device
Using the API
Authentication

Most API endpoints require authentication using an API key. Include your API key in the request headers:

Authorization: Bearer YOUR_API_KEY
Request Format

The API accepts and returns JSON data. Set the appropriate content type:

Content-Type: application/json
Example Request
curl -X GET "https://api.safecast.org/api/v1/measurements" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json"
